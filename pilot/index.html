Five LLM agents operate a browser from a plain-English goal, by reading the screen

Pilot types, clicks and scrolls in a real browser to carry out a goal such as "Move this lead to Proposal Sent", purely by looking at screenshots: no per-app API and no brittle page selectors. A verifier agent checks every step and sends a failed one back to the planner. It is a working prototype, and this page says plainly what it does not yet prove.

01The question

Can an agent operate any web app it can see, with no integration work for each one?

02The method

Five agents run as a loop. A screen interpreter turns a screenshot into structured UI state; a planner breaks the goal into steps; an action agent chooses a click, keystroke or scroll with pixel coordinates; a verifier looks at a fresh screenshot and either passes the step or triggers replanning; a narrator describes each step in the side panel.

It is built with a FastAPI backend (REST and WebSocket) and a Chrome Manifest V3 side-panel extension that dispatches real mouse and keyboard events through Chrome's debugger protocol. Each agent has its own prompt and returns JSON.

03Reliability so far

A code review on 2026-10-07 fixed three faults: replanning had no limit (it is now capped at 3 per goal), clicks on scaled displays landed at a multiple of the intended point (the extension now divides by the device pixel ratio), and a click outside the screenshot now fails the step instead of firing. 11 tests, with every model call stubbed, cover the loop.

04What this does not show

  • It is a prototype: session state is in memory, and the Terraform and Docker files are deployment scaffolding, not a verified live deployment.
  • There is no measured success rate. The repository holds a reliability model, but every rate in it is an assumption, not a measurement of Pilot.
  • That model suggests the verifier sets the ceiling: in a six-step base case, about one run in ten that Pilot reports as complete would be wrong, whatever the replan cap.
  • Every step costs a Gemini vision call, and reliability depends on the verifier catching mis-clicks.

05Reproduce it

cd backend && pip install -r requirements.txt
export GOOGLE_API_KEY=your_key_here && python main.py
cd ../extension && npm install && npm run build   # load extension/dist/ unpacked in Chrome
